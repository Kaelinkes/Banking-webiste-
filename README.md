## About  
This project is a simple banking web application built with PHP designed for learning and demonstration purposes. It allows users to view accounts, transfer funds, and simulate banking operations via a web interface.

## Features  
- User account overview  
- Transfer funds between accounts  
- Transaction history / logging (depending on implementation)  
- Basic error handling (e.g., insufficient funds)  
- Web interface built in PHP  

## Tech Stack  
- **Backend:** PHP  
- **Frontend:** HTML / CSS / Javascript  
- **Database:** No databse being used, sessions and cookies are being used.
- **Hosting / Deployment:** Local or shared PHP-enabled web hosting
  
## Usage
- To make a transfer: select source account, target account, input amount, and submit.
- Check transaction history to see the effect of the transfer.
- The site simulates basic banking behaviour and is meant for demonstration only (not for production use).
